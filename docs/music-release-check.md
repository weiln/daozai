# 音乐兼容性：本版发版前手动检查

本版只包含两处局部修改：进程访问收窄、歌词重试真正重查。以下检查请用真实播放器完成。

## 1. 进度与信息不退步

| 播放器 | 检查项 | 结果 |
|---|---|---|
| 网易云（已适配版本） | 进度条走动、拖动、歌词逐句滚动与修改前一致 | ☐ |
| 酷狗（已适配版本） | 进度条走动、歌词同步、缺时长时能补全歌手和时长 | ☐ |
| QQ 音乐 / 汽水 | 歌名、封面、歌词正常（本次未改，作对照） | ☐ |
| 任一播放器 | 播放、暂停、切歌、拖动走一遍无异常 | ☐ |
| 关闭再重开播放器 | 几秒内恢复进度显示（重新发现进程） | ☐ |

## 2. 不再接触其他软件

1. 打开企业微信、浏览器等软件，再播放网易云或酷狗。
2. 用 Process Explorer（Sysinternals）选中岛仔进程，打开下方 Handles 视图，筛选类型为 Process 的句柄。
3. 预期：带内存读取权限的句柄只指向网易云 / 酷狗；企业微信等其他进程最多只出现“有限查询”权限的短暂句柄。

结果：☐

## 3. 歌词重试

1. 播放一首确定查不到歌词的歌，等待显示「未找到匹配歌词」。
2. 点击「点击重试」。
3. 打开 `%APPDATA%\Daozai\diagnostics\lyrics.log`，最新一行应出现「手动重试:跳过无歌词记录」，并有实际联网查询步骤。
4. 不点重试、自然切回这首歌时，应仍命中「近期已确认无同步歌词」，不重复联网。

结果：☐
